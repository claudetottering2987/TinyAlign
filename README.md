## 📋 What is TinyAlign?

TinyAlign takes existing vision-language models and improves their internal structure. Modern artificial intelligence models often struggle to match image data with text data. This creates a bottleneck. TinyAlign removes this hurdle. 

The project uses the TinyLLaVA Factory framework to ensure efficiency. It functions well on standard personal computers. You do not need expensive graphics cards or server hardware to see results. The code optimizes the way your processor handles information from images.
